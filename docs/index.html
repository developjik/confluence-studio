Features

위키를 다루는 일이, 전부 하나의 창에서

Confluence Cloud v2 REST API 위에 네이티브 속도의 Rust 백엔드를 얹었습니다. 브라우저 탭 몇 개가 하던 일을 하나의 키보드 중심 앱으로.

스페이스 & 페이지 트리

모든 스페이스를 트리로 탐색하고 하위 페이지를 펼쳐 바로 열람. 스페이스 루트는 헤더로, 페이지는 클릭 한 번으로.

Markdown 편집 = Confluence 저장

quick-xml 기반 변환기가 storage XHTML과 Markdown을 왕복 변환합니다. 편집한 내용은 실제 Confluence 버전 히스토리로 기록됩니다.

페이지 CRUD

생성·수정·삭제 전부 앱 안에서. CodeMirror 에디터로 쓰고 react-markdown으로 바로 미리보기.

예약 export 잡

스페이스 전체나 특정 페이지 하위 트리를 로컬 Markdown으로. 첨부파일 포함, 변경 없는 문서 건너뛰기, 병렬 워커로 빠르게.

Damon AI 채팅

Damon 데몬(프로토콜 v2 WebSocket)의 thin client. 세션 관리, 스트리밍 응답, 도구 사용 허가 프롬프트까지 지원합니다.

안전한 자격증명

Confluence API 토큰은 OS 키체인(macOS Keychain / Windows Credential Manager)에만 저장됩니다. 설정 파일에 평문으로 남기지 않습니다.

Scheduled exports

위키가 알아서 로컬 파일로

confluence-export-desktop(Python)의 잡 의미론을 그대로 이식했습니다. 정해진 시간에 스페이스를 Markdown으로 내려받고, 실행 기록을 남깁니다.

Storage ↔ Markdown

저장 포맷을 몰라도 됩니다

열람 시 storage XHTML을 Markdown으로, 저장 시 Markdown을 storage로 되돌립니다. 제목·리스트·본문 텍스트는 왕복에서 유실되지 않도록 테스트로 지킵니다.
